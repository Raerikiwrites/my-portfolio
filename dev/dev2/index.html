    Taking a Step Back to Start Strong

    September 3, 2025

    This is day 2 of my From Scratch series, where I’ll be documenting my programming and blockchain development journey. My approach is actually quite simple: master the fundamentals before moving on.

    Yesterday I jumped right into Solidity, but today I’ve decided not to skip anything. I’ll first complete a 3-week JavaScript course, then move on to a 7-week Ethereum bootcamp from Alchemy University, and finally revisit CryptoZombies. I hope this approach will help me achieve my goals without experiencing a “learners block” (P.S: I don’t know if that’s an actual thing).

    In this post, I’ll share what I learned today, from JavaScript basics like numbers, variables, and strings, to functions and conditionals. I want this series to be a clear roadmap for anyone looking to start from scratch, just like me.

    Introduction to JavaScript

    I’m learning JavaScript through Alchemy University’s Learn JavaScript course, which is meant to help me build a strong foundation before diving into blockchain and Ethereum development.

    JavaScript is a programming language that lets you talk to your computer and tell it exactly what to do. Let’s dive in!

    Numbers and Variables

    A variable is a name we give to a value so we can store it and use it later. Think of it like giving a label to a piece of information in your program.

    1. Single Variable

    let age = 21;       // "age" stores the value 21
console.log(age);   // prints 21

    Here’s what happens:

    • let → tells JavaScript we want a variable whose value we might change later.
    • age → the name of the variable.
    • 21 → the value stored in the variable.
    • console.log(age) → shows the value of the variable on the screen.

    2. Multiple Variables

    let x = 5;
let y = 10;
let z = 15;

console.log(x, y, z); // prints 5 10 15

    You can create multiple variables at once. Each variable has its own name and stores its own value.

    3. Using Variables Together 

    let sum = x + y + z; 
console.log(sum); // prints 30

    You can do math with the numbers stored in your variables. Here, JavaScript adds the numbers from each variable and stores the result in a new variable called sum.

    Booleans

    let isSunny = true;
let isRaining = false;
console.log(isSunny);   // prints true
console.log(isRaining); // prints false

    A Boolean is a value that can only be true or false. It’s useful when you want to represent something that has only two options.

    Tip: Think of Booleans as yes/no answers for your program.

    Strings

    A string is a type of data that stores text. Anything inside quotes (single or double) is a string.

    • Simple Strings
        let name = "Mariam";
    let greeting = 'Hello';
    console.log(name);     // prints Mariam
    console.log(greeting); // prints Hello
    • Combining Strings
        let message = greeting + ", " + name + "!";
    console.log(message); // prints Hello, Mariam!


    Tip: Strings are like words or sentences in your program. You can combine them, change them, and display them on the screen.

    Mutable Variables (let)

    A mutable variable is a variable whose value you can change later. We use let to create these variables in JavaScript.

    Changing Text
let color = "blue";     // color starts as blue
console.log(color);     // prints blue

color = "green";        // now color is green
console.log(color);     // prints green


    Tip: Think of let like a name tag you can rewrite whenever you need.

    Comments

    Comments are notes you write in your code to explain what it does. The computer ignores comments. They’re just for you or anyone reading your code.

    • Single-line comment starts with //
    // This is my first comment
let age = 21;  
console.log(age);


    • Multi-line comment starts with /* and ends with */
    /*
This is a multi-line comment
It can cover several lines
Use it to explain bigger parts of your code
*/
let color = "blue";
console.log(color); // prints blue


    Tip: Use comments to remember what your code does or to explain it to someone else.

    Functions

    A function is like a mini-program you can use to do something specific. Once you create it, you can use it anytime without rewriting the code.

    addTwo() – adds 2 to a number

        function addTwo(number) {
      return number + 2;
    }

    console.log(addTwo(5));  // prints 7

    How it works:

    • function addTwo(number) → creates a function called addTwo that takes one input called number.
    • return number + 2; → adds 2 to the input and gives the result back.
    • addTwo(5) → calls the function with 5 as input. The result is 7.


    multiply() – multiplies two numbers

        function multiply(a, b) {
      return a * b;
    }

    console.log(multiply(3, 4)); // prints 12

    Note: return a * b; → multiplies the two numbers and gives the result back.


    average() – calculates the average of two numbers

    function average(a, b) {
  return (a + b) / 2;
}

console.log(average(4, 6));  // prints 5


    random() – gives a random number between 0 and 1

    console.log(Math.random()); // prints a number like 0.123456


    floor() – rounds a number down to the nearest whole number

     console.log(Math.floor(4.9));  // prints 4
 console.log(Math.floor(7.1));  // prints 7


    Tip: Functions help you reuse code, do math, and work with numbers and text more easily.

    Conditionals

    A conditional is a way for your program to make decisions. It lets your code do one thing if something is true and another if it’s false.

    isEqual – checks if two values are the same

       let a = 5;
   let b = 5;

   console.log(a === b); // prints true
    • === checks if the two values are equal and of the same type. If they are equal, it returns true.

    notEqual – checks if two values are different

    let a = 5;
let b = 3;

console.log(a != b); // prints true
    • != checks if the two values are not equal. If they are different, it returns true.

    greaterThan – checks if a number is bigger than another

    let a = 10;
let b = 5;

console.log(a > b); // prints true
    • > checks if the first number is greater than the second number. Returns true if it is, false if it isn’t.

    else – gives a result if the first condition isn’t true

    let a = 3;
let b = 5;

if(a > b) {
  console.log("a is bigger");
} else {
  console.log("b is bigger"); // prints this
}

    • if checks the condition (a > b).

    • If it’s true, it runs the first block.

    • If it’s false, it runs the else block.

    else if – checks multiple conditions

    let a = 5;

if(a > 10) {
  console.log("a is bigger than 10");
}

else if(a == 5) {
  console.log("a is 5"); // prints this
}

else {
  console.log("a is something else");
}
    • else if lets you check another condition if the first one is false.
    • You can add as many else if blocks as needed.

    Tip: Conditionals are like decision points in your code; your program can choose what to do based on the information it has.

    Closing Thoughts on Day 2

    Yayy, another day done, and I actually feel like I’m starting to get the hang of JavaScript. Playing around with numbers, text, and Booleans was way easier than I expected. Writing my first functions and seeing them work felt like a mini “aha!” moment.

    I did stumble a few times, especially figuring out how let works when changing values, but that’s okay. It’s all part of learning. I’m excited to see how tomorrow’s practice will help me connect all these little pieces together.

    For now, I’ll take a break, maybe review my notes, and just enjoy the fact that my code actually ran without errors today. Baby steps!
